### 🎓 LectureMind AI — AI Study Assistant for Lecture Videos

An AI-powered study assistant that converts **YouTube lecture videos into structured study material**.

**Key Features:**
- 🎥 Converts YouTube lectures into structured study content
- 🗣️ Uses OpenAI's Whisper Speech-to-Text model for accurate transcription
- 📝 Generates smart summaries and subject-tagged notes
- 🃏 Automatically creates AI-generated flashcards
- ❓ Generates multiple-choice quizzes
- 📚 Detects subject context such as Physics, Chemistry, Biology, or Mathematics
- ⏱️ Provides timestamped highlights for important concepts
- ⚡ React frontend with Python FastAPI backend
- 📱 Supports offline functionality using service workers

**Technologies:** Python | FastAPI | React | OpenAI Whisper | NLP | LLM | YouTube API
